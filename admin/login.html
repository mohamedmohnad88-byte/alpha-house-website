لوحة إدارة Alpha House Real Estate

إعداد Firebase (مرة واحدة):
1. Firebase Console → Authentication → Users → Add user (email + password)
2. انسخ UID → Firestore → collection "users" → document ID = UID → field: role = "admin"
3. Firestore → Rules → الصق firestore.rules → Publish
4. (اختياري) Storage → Rules → الصق storage.rules → Publish
